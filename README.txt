CUSTOMER SERVICE PORTFOLIO WEBSITE

Preview: open index.html in a browser.

Publish with GitHub Pages:
1. Create a new GitHub repository (or use a separate portfolio repository).
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and / (root), then Save.
5. Wait for GitHub Pages to provide the published URL.

Before publishing:
- Confirm your email and location may be public.
- Sample messages are illustrative, not actual customer records.
- Never include real customer names, phone numbers, account details, loan balances, or confidential information.
- Only add achievements or metrics you can verify.
